# Древо — памятка для работы над кодом

Закрытое семейное генеалогическое дерево для телефона (PWA). Описание возможностей — `README.md`, исходный замысел и разбор аналогов — `docs/proekt.md`, план и статусы задач — `docs/plan.md`.

## Устройство

- `server/` — Node.js 22, Fastify, PostgreSQL, PDF через pdfkit. Миграции `server/migrations/NNN_*.sql` применяются при старте.
- `web/` — Vue 3 + Vite + PWA, без TypeScript.
- `shared/` — общий код телефона и сервера: имена, родство, раскладка дерева, разбивка печати.
- Ключевые модули сервера:
  - `src/db.js` — `tx()`: у каждой транзакции свой `op`, общий номер всех записей журнала за одно действие.
  - `src/changes.js` — `logChange()` (журнал правок) и `listOps()` (действия целиком).
  - `src/tree.js` — связи между людьми, удаление и возврат человека, `HttpError`.
  - `src/revert.js` — откат действия целиком; у каждого типа записи журнала есть обратная операция.
  - `src/privacy.js` — что скрывать от гостей.
  - `src/push.js` — уведомления на телефон (Web Push): кому что слать, расписание раз в минуту, отметки «уже отправлено».
  - `src/events.js` — поток обновлений `/api/events` из PostgreSQL `NOTIFY`.

## Правила

- Интерфейс, сообщения и комментарии в коде — по-русски, коротко и просто: приложением пользуются пожилые родственники.
- Любое изменение дерева идёт внутри `tx()` и пишется через `logChange(db, …)`, чтобы попасть в журнал и откатываться. Новый тип записи журнала требует обратной операции в `src/revert.js` и подписи в `web/src/history.js`.
- Гости (роль `viewer`) не видят дат, мест, заметок и фото живых моложе 100 лет (`isPrivate` в `shared/names.js`, `hideLiving` в `src/privacy.js`). Всё новое, что отдаёт гостям данные людей, проходит через это правило.
- Ошибки для пользователя: `throw new HttpError(код, 'понятный текст')`, их отдаёт общий обработчик.
- Свой сервер в России: никаких внешних сервисов, CDN и облаков (см. `docs/proekt.md`, раздел 7).

## Проверки

В облачном контейнере PostgreSQL установлен, но не запущен:

```sh
service postgresql start
su postgres -c "psql -c \"create user drevo with password 'drevo' superuser;\" -c \"create database drevo owner drevo;\""
cd server && npm ci && npm test        # тесты очищают базу drevo
cd ../web && npm ci && npm run build
```

Изменения интерфейса проверять в браузере: Chromium и Playwright установлены (`require('playwright')` из `/opt/node22/lib/node_modules/`). Данные для проверки: `node server/bin/demo.js` (очищает базу и печатает ссылку входа владельца), сервер: `cd server && SECURE_COOKIES=false PUBLIC_URL=http://localhost:8095 npm start`, интерфейс собирается в `web/dist` и раздаётся тем же сервером.
