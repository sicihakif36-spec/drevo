# С.1. Несколько семей на сервере

Запрос владельца (25.10.2026), чат с владельцем напрямую, без отдельного задания:

> У приложения должна быть возможность создавать несколько семей. Это ещё не речь о масштабировании. У владельца должна быть возможность делить ссылкой. Пользователей, создающих свои семьи на сервере, будет до 20.

## Ответы владельца на вопросы

1. **Кто раздаёт ссылки «Завести своё дерево»** — только владельцы главной семьи (той, что уже на сервере), в «Ещё → Семьи на сервере». Кто открыл ссылку — владелец новой пустой семьи. Не больше 20 семей, кроме главной.
2. **Видят ли владельцы главной семьи чужие деревья** — нет, только список: название, владелец, сколько людей и места, когда заходили; можно закрыть вход в семью. Деревья полностью разделены.
3. **Один телефон в нескольких семьях** — да, с переключателем: ссылка из другой семьи добавляет её, а не выводит из своей; в «Ещё» — «Мои семьи»; роль и пароль в каждой семье свои.
4. **Место на диске** — предел для каждой семьи, который владелец главной семьи меняет (по умолчанию 5 ГБ); при превышении не загружаются новые файлы, остальное работает.

## Как проверить

- `server/test/families.test.js`: ссылку делают только владельцы главной семьи, по ней — новая пустая семья; деревья, журнал, участники, файлы, GEDCOM, архив — каждой семьи свои; приглашения и ссылки без входа (вопрос, анкета, интервью) ведут в свою семью на любом телефоне; телефон в двух семьях: «Мои семьи», переключение, выход из одной; поток обновлений и уведомления — своей семье, у телефона из двух семей — с названием дерева и ссылкой в семью; список семей без содержимого деревьев, предел места, «Закрыть вход»; не больше предела семей; запрос к базе вне семьи — ошибка; восстановление входа владельцу другой семьи и удаление семьи скриптом, пока сервер работает.
- Все прежние тесты зелёные, `npm run build` в `web` проходит; в браузере 390×844: ссылка, новая семья с паролем, приглашение из другой семьи, «Мои семьи», «Семьи на сервере», закрытый вход, нажатие на уведомление из другой семьи.
