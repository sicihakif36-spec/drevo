## Как сейчас

Вход только по личной ссылке-приглашению от владельца: одноразовая, 14 дней (до 90), ключ 256 бит, на сервере только хеш. После входа — сессия на год (httpOnly, Secure, SameSite=strict). Владелец видит участников и когда заходили, «Отключить» удаляет все их сессии; «Ссылка для входа на новом телефоне» — на 3 дня. Ограничение: 20 попыток входа за 10 минут с адреса. Слабые места: перехваченной (пересланной) ссылкой входит тот, кто открыл первым, и владелец об этом не знает; сам человек не видит своих устройств и не может выйти везде; кто правит дерево, защищён только телефоном.

## Решение владельца (24.10.2026)

Вход по ссылке **остаётся** (пожилым так проще), логинов как основного входа нет. Добавить:

1. **Уведомление владельцу о каждом новом входе** — по приглашению и по ссылке на новом телефоне: на телефон (Web Push, если включены уведомления) и списком «Входы» в «Ещё → Родственники и приглашения»: «Вошла Ольга (участник) — Android, Chrome · 24 октября, 14:05». Кнопка **«Это не она — отключить»**: отключает человека, выводит со всех устройств и предлагает сразу сделать новую ссылку настоящему человеку. Устройство — понятными словами из user-agent, без внешних служб. Храни входы 90 дней.
2. **Ссылка-приглашение по умолчанию на 3 дня** (выбор: 1, 3, 7, 14 дней). Уже выданные ссылки живут до своего срока.
3. **«Мои устройства»** у каждого (в «Ещё», рядом с выходом): где вы вошли (устройство, когда были, «это устройство»), «Выйти на этом» и «Выйти на всех, кроме этого». У владельца в списке участников — то же для любого человека и «Выйти на всех устройствах» без отключения.
4. **Пароль у владельца и участников (роль `editor` и выше) при входе с нового устройства.**
   - При первом входе (или на ближайшем открытии у уже вошедших) — экран «Придумайте пароль»: не короче 8 знаков, не из списка простых (`12345678`, `qwerty…`, повтор одного знака), показать/скрыть, понятные подсказки. Хранить — `crypto.scrypt` с солью (без новых зависимостей), сравнение за постоянное время.
   - Вход существующего участника по ссылке на новом телефоне — после ссылки ещё и пароль; без пароля сессия не начинается (не «полу-вход»: неподтверждённая сессия не даёт ни одного API, кроме ввода пароля). Неверный пароль — не больше 5 попыток, потом ждать 15 минут (по человеку и по адресу); после 5 неверных — уведомление владельцу.
   - Родственникам и гостям пароль не нужен. Повысили роль до участника — попросит придумать пароль при следующем открытии.
   - «Сменить пароль» в «Ещё → Мои устройства» (старый + новый; смена выводит со всех остальных устройств).
   - **Забыл пароль**: владелец в списке участников — «Сбросить пароль» (с подтверждением) и новая ссылка; по ней человек придумывает новый. Владелец, забывший свой пароль, — `sudo bash /srv/drevo/current/deploy/…` (сделай понятную команду по образцу `deploy/invite.sh`, опиши в памятке).
   - Уже вошедшие на своих телефонах продолжают работать без повторного ввода (пароль нужен при входе на новом устройстве), но участник без пароля не может править дерево, пока его не придумает.
5. **Мелочи безопасности**, если найдёшь: сессии, которыми не пользовались больше года, удалять; заголовки и cookie проверить; ограничение попыток не должно сбрасываться перезапуском так, чтобы это помогало перебору (реши, нужно ли хранить в базе). Ничего внешнего (CAPTCHA, SMS, почта) — правило проекта.
6. **Демо и тесты должны остаться простыми:** `node server/bin/demo.js` печатает ссылку входа владельца и пароль демо (или ставит его сам), тестовые помощники входа в `server/test/` работают для всех ролей — чтобы следующие чаты не мучились.

Тексты — по-русски, крупно и просто: «Придумайте пароль — он нужен, только когда вы входите с нового телефона».

## Как проверить

- Тесты: уведомление и запись о входе (по приглашению и по ссылке), «Это не он — отключить»; срок ссылки по умолчанию 3 дня; «Мои устройства»: список только своих, выход на одном, «на всех, кроме этого», чужую сессию закрыть нельзя (кроме владельца); пароль: требования, хеш (в базе нет пароля открытым текстом), неподтверждённая сессия получает 401/403 на всё, кроме ввода пароля, 5 попыток → ожидание, уведомление владельцу, смена пароля выводит остальных, сброс владельцем; родственник и гость входят без пароля; старые сессии участников работают, но правка без пароля закрыта; команда сброса пароля владельца. Все прежние тесты зелёные, `npm run build` в `web` проходит.
- В браузере (Playwright, 390×844, демо): приглашение участника → вход → «Придумайте пароль» → работа; владелец видит «Вошёл…» и отключает; вход участника на «новом телефоне» (новый контекст браузера) по ссылке → пароль → неверный 5 раз → ожидание; «Мои устройства», «Выйти на всех, кроме этого»; родственник входит без пароля. Посмотри снимки сам и исправь то, что выглядит плохо.
- Перечитай дифф придирчиво: это безопасность — каждый путь входа (приглашение, ссылка на новый телефон, `bin/invite.js`, анкеты по своей ссылке, `/api/events`, медиафайлы) не должен обходить пароль и уведомление.
