# План работ

Порядок согласован с владельцем. Каждая задача делается в отдельном чате, результат отправляется в ветку `claude/clever-pasteur-kv36do`. Слияние в `main` и установка на сервер — в конце, по решению владельца.

Статусы: ✅ готово · 🔄 в работе · ⏳ следующая · ⏸ отложено · — не начато.

## Шаг 1. Доделать первый этап — ✅

- ✅ Гости не видят дат, мест, заметок и фото живых.
- ✅ Откат действий целиком, включая связи; отменённое можно вернуть.
- ✅ Мелкие ошибки API, общий обработчик ошибок.
- ✅ Проверки на GitHub (тесты и сборка).
- ⏸ Импорт GEDCOM — не нужен: другого дерева нет.

## Шаг 2. Запуск для семьи — ⏸

Слить в `main`, обновить сервер (`deploy/install.sh`), раздать приглашения. Отложено до конца по решению владельца.

## Шаг 3. Совместность

- ✅ 3.1. Лента «что нового»: вкладка в нижней панели вместо «Печати» (печать уходит в «Ещё»), действия родственников из журнала, отметка нового с прошлого визита, ближайшие дни рождения живых и памятные даты ушедших, подсказки, что заполнить. Гостям — без скрытых данных.
- ⏳ 3.2. Обсуждение у карточки человека: комментарии, видны в ленте.
- — 3.3. Обновления у всех сразу (сейчас раз в минуту).
- — 3.4. Уведомления: Web Push и, по желанию, Telegram-бот (нужен токен бота от владельца).
- — 3.5. Хранители веток и правки «на проверку».

## Шаг 4. Больше данных

Несколько фото и документы у человека, истории и голосовые записи, источники с отметкой достоверности, хронология событий, исторические названия мест, даты по старому стилю.

## Шаг 5. Печать «под подарок»

Веерная схема предков, карточка человека в PDF, семейная книга, поколенная роспись, бланк-опросник, полный архив в ZIP.

## Шаг 6. Без интернета и полировка

Правки без связи с синхронизацией, крупный шрифт для пожилых, ручной выбор темы (сейчас тёмная тема включается по настройке телефона).
