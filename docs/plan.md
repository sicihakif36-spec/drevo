Слить в `main`, обновить сервер (`deploy/install.sh`), раздать приглашения. Отложено до конца по решению владельца.

### Проверить при установке

- `nginx -t` проходит (установщик делает сам).
- У сервера и контейнера есть выход к службам уведомлений браузеров (Google, Apple, Mozilla, Microsoft).
- «Прислать проверочное» доходит на Android (Chrome) и на iPhone с экрана «Домой».
- Уведомления включаются в браузерах, которыми пользуются родственники (например, Яндекс Браузер); иначе дополнить список служб в `server/src/push.js`.
- Формулировки сводки и время 9:00 устраивают.
- Загрузка крупного скана или PDF проходит через nginx (`client_max_body_size 25m`, сервер принимает файл до 20 МБ).

## Шаг 3. Совместность

- ✅ 3.1. Лента «что нового»: вкладка в нижней панели вместо «Печати» (печать уходит в «Ещё»), действия родственников из журнала, отметка нового с прошлого визита, ближайшие дни рождения живых и памятные даты ушедших, подсказки, что заполнить. Гостям — без скрытых данных.
- ✅ 3.2. Обсуждение у карточки человека: комментарии, видны в ленте.
  Пишут участники и владелец; изменить — только автор, удалить — автор или владелец (удаление мягкое). Гости читают, но не обсуждения живых — ни в карточке, ни в ленте, ни в подсчёте новых. В журнал правок не пишется.
- ✅ 3.3. Обновления у всех сразу.
  Поток `GET /api/events` (Server-Sent Events) из PostgreSQL `NOTIFY` по журналу правок, обсуждению и настройкам; события без данных людей, гостю — без обсуждений живых. Без потока телефон перечитывает дерево раз в минуту и пробует подключиться снова.
- ✅ 3.4. Уведомления. Решение владельца: Telegram-бот не нужен, уведомления — только Web Push из самого приложения.
  Новый комментарий — сразу; правки — сводкой по автору после 10 минут тишины; дни рождения и памятные даты — в 9:00 по Москве. У каждого три переключателя в «Ещё → Уведомления». Гостю — без данных живых. Ключи VAPID в отдельной таблице `push_keys`, подписка живёт, пока жив вход с телефона. Открытый поток `/api/events` раз в 25 секунд перепроверяет вход.
- ⏸ 3.5. Хранители веток — перенесено в «После запуска для семьи».
