# Оформление: концепция (этап Д.1)

Разбор удобства и три варианта нового вида. Страница для владельца со снимками «как сейчас → как будет» и иконками на экране «Домой»: https://claude.ai/artifact/MMnAU6LJuwKTEBSht3Z51i (приватная, показывает только демо-семью).

Ждёт выбора владельца: вид (А, Б или В), иконка, согласие с исправлениями текстов. Совет: вид А и иконка «Крона».

## Как снимали

Демо-семья (`node server/bin/demo.js`), Playwright, Chromium, 390×844 и 360×780. Крупный шрифт телефона изображали уменьшением ширины окна при том же масштабе: 300 точек ≈ 130 %, 260 точек ≈ 150 % (так работает масштаб текста в Chrome на Android). Варианты стиля — настоящее приложение с подставленным CSS (`page.addStyleTag`), экраны не переделывались. Контраст считали по формуле WCAG 2.1.

## Проблемы по важности

### Мешают пользоваться

1. **Поиск на дереве спрятан под нижней панелью.** Дерево → лупа: затемнение есть, поле ввода закрыто `.nav`. Причина: `.tree-page` — `position: fixed`, это свой слой наложения, и `z-index: 41` у `.sheet` внутри него ниже `.nav` (`z-index: 30`) в корне. Исправить: вынести шторку поиска из `.tree-page` (как `AddPersonSheet` в `App.vue`) или открывать поиск сверху экрана. Ошибка кода, можно чинить отдельно от нового вида.
2. **Буквы на дереве меньше 10 пикселей.** Дерево открывается с масштабом 0,65 (`TreeCanvas.vue`, `view.k`), в рамке шрифты 16/14/13 → на экране 10,4/9,1/8,5 пикселя, годы ещё и серые. Исправить: начальный масштаб 0,9–1,0, шрифты в рамке 18/16/15, годы цветом текста; при дальнем масштабе (`detail === 1`) — фамилия и имя по 24.
3. **Бледный мелкий текст.** `--muted #7a7166` на `--bg #f7f3ec` — 4,33 : 1 (норма AA 4,5), а применяется к 13-пунктовым подписям полей (`.field > span`, `.small`), годам, пояснениям. Ссылки и зелёный текст `#5b7a3a` на фоне — 4,43 : 1; зелёный на светло-зелёном (значки «документ», `.badge`) — 4,10 : 1. Исправить: основной текст 18, подписи 16 полужирные цветом текста, приглушённый цвет не ниже 6,5 : 1.
4. **Кнопки и поля сливаются с фоном.** Второстепенная кнопка `--accent-soft #e6eed9` на `--bg` — 1,08 : 1, рамка полей и карточек `--line #e4ddd1` на белом — 1,35 : 1 (норма для элементов управления 3 : 1, WCAG 1.4.11). Выбранный пункт переключателя (`.seg button.on`) — белое на `#e4ddd1`, 1,2 : 1. Исправить: рамка полей 1,5–2 точки ≥ 3 : 1; второстепенные кнопки с рамкой или плотной заливкой; выбранный пункт — рамка цвета приложения.
5. **Крупный шрифт телефона ломает экраны.** При 150 %: в карточке подпись «Дата рождения» сжимается рядом со значком источника, подсказка в поле даты обрезана («1950 или о»: два поля дат в `.grid2`), в ленте колонка даты (`.when`, 84 px) съедает треть ширины, имя переносится по слову. На iPhone размеры в `px` не следуют крупному шрифту системы. Исправить: размеры в `rem`, `html { font-size: 112.5% }` (1rem = 18px и учитывает настройку браузера); для iPhone — `font: -apple-system-body` на `html` с последующим пересчётом в `rem` (проверить на устройстве); значок источника под значением; поля дат по одному в строку; дату в ленте — строкой над именем.
6. **Красные ✕ рядом с родными в правке.** Карточка → «Изменить» → «Семья»: у супруга и каждого ребёнка маленький ✕ (`PersonView.vue`, `unlink`), подтверждение — окно браузера `confirm()`. Исправить: в правке не показывать ✕; «Убрать связь» отдельным действием внутри строки и своё окно с понятными кнопками.

## Варианты стиля

Общее для всех: размеры в `rem`; основной текст 18–19, подписи 16–17, заголовок страницы 28–30, раздела 20–21 цветом текста (не серым); кнопки и поля 54–58; цели нажатия ≥ 48; рамка фокуса 3 точки цветом акцента; нижняя панель 78–80 + подписи 14 + подложка у выбранного раздела + подпись «Добавить»; аватар 52; строки списков ≥ 60. Шрифты — из пакетов `@fontsource/*` (OFL), подключаются в `main.js`, Vite кладёт файлы `woff2` в сборку: работают при нынешнем CSP `font-src 'self'`, без внешних серверов. Брать только кириллицу и латиницу, начертания 400 и 700 (у Golos — 400/600/700), `font-display: swap`.

Дерево во всех вариантах: начальный масштаб 0,9–1,0; линии 2,5 цветом не светлее `--edge`; рамка 2,5, выбранный — 5–6 цветом акцента; в рамке фамилия 18 (шрифт заголовков), имя 16, годы 15. Размер рамки `BOX` в `shared/layout.js` общий с печатью — менять только вместе с проверкой PDF.

## План этапа 2

Порядок — от общего к частному, после каждого шага снимки Playwright 390/360/«150 %» и сборка.

1. **Токены и шрифт.** `web/src/style.css`: токены выбранного варианта (светлая и тёмная), размеры в `rem`, `html { font-size: 112.5% }`; шрифт — `@fontsource/*` в `web/package.json`, импорт в `web/src/main.js`.
2. **Общие элементы.** `style.css`: кнопки (главная, второстепенная, опасная), поля, `.seg`, `.chip` (перенос строк вместо прокрутки), `.list`, `.card`, `.sheet`, `.toast`, `.banner`; фокус. `App.vue`: нижняя панель — подписи 14, подложка выбранного, подпись «Добавить».
3. **Свои окна вопросов.** Компонент `Confirm` (и ввод имени) вместо 25 вызовов `confirm()`/`prompt()` по `web/src`.
4. **Дерево.** `components/TreeCanvas.vue` (масштаб, шрифты, цвета узлов), `views/TreeView.vue` (поиск поверх панели — ошибка из п. 1, кнопки с подписями, шторка выбранного человека сеткой).
5. **Карточка.** `views/PersonView.vue` (закладки разделов, ✕ только в режиме «Связи» с вопросом), `components/FactBadge.vue` (под значением, слова), `components/DateInput.vue` (подпись как у полей), `components/Album.vue`, `components/Stories.vue`, `components/StoryView.vue` (голос первым), `components/Discussion.vue`.
